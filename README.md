# Student Manager

基于 C++ 和 EasyX 图形库实现的可视化学生需求服务管理系统，支持账号注册登录、需求发布与管理，数据通过链表组织并持久化到本地文件。

## 功能特性

- **账号系统**：支持注册、登录，账号信息本地文件存储
- **需求管理**：发布、查看、搜索、删除需求信息
- **分类管理**：需求按类别分组管理
- **可视化界面**：基于 EasyX 图形库的 GUI 交互
- **数据持久化**：链表结构 + 本地 txt 文件读写

## 项目结构

```
├── 源.cpp                # 主程序入口
├── login.h / login.cpp   # 登录注册模块
├── person.h / person.cpp # 用户信息类
├── demand.h / demand.cpp # 需求信息类（双向链表节点）
├── events.h / events.cpp # 需求事件管理（链表操作）
├── account/              # 账号数据存储
├── file/                 # 需求数据存储
└── 使用说明/              # EasyX 安装包及使用文档
```

## 环境准备

1. **IDE**：Visual Studio（推荐 VS2019+）
2. **图形库**：安装 EasyX（安装包位于 `使用说明/EasyX_20210224.exe`）
3. 使用 VS 打开 `Project1.sln` 即可编译运行

## 使用说明

1. 启动程序后进入登录界面，可注册新账号或登录已有账号
2. 登录后进入主界面，可进行需求的发布、浏览、搜索和删除等操作
3. 所有数据自动保存至本地文件，下次启动时自动加载
